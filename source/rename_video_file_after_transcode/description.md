
Rename files after processing so any codec, resolution, bit-depth, or HDR/SDR tokens in the name reflect the current media. Uses the bundled ffprobe helper, requires no configuration.

**Note:** Place this plugin before any notification plugins (e.g., Notify Sonarr or Notify Radarr) so downstream apps see the corrected filename.
